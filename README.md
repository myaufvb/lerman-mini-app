# 🛡️ Lerman Mini App & Cyber Security Projects Hub

Комплексное Telegram Mini App приложение и Telegram-бот для мониторинга проектов, зашифрованного хранения паролей/доступов, фото/видео медиа, тикетов техподдержки и мгновенных оповещений в Telegram.

---

## 🌟 Ключевые возможности

1. **Мониторинг проектов & Uptime 24/7**:
   - Автоматическая проверка доступности сайтов и API каждые 60 секунд.
   - Измерение задержки отклика (Latency ms).
   - Мгновенный тревожный сигнал в Telegram при падении сайта (`502 Bad Gateway`, `Timeout` и др.) и оповещение при восстановлении.
   - Кнопка ручного пинга в один клик.

2. **Сейф паролей и доступов (Vault) с шифрованием AES-256-GCM**:
   - Безопасное хранение логинов, паролей, API-токенов, SSH-ключей и баз данных.
   - Защита раздела **Master PIN** кодом.
   - Копирование логина и пароля в один клик с визуальным подтверждением.
   - Встроенный генератор криптографически стойких паролей.

3. **One-Time Secret (Burn-on-Read)**:
   - Создание защищенных одноразовых ссылок на пароли или конфиги.
   - Ссылка самоуничтожается без следа после первого прочтения получателем.

4. **Медиатека (Фото & Видео)**:
   - Загрузка скриншотов багов, видеозаписей демонстраций, диаграмм и ТЗ.
   - Встроенный полноэкранный просмотрщик фото и HTML5 видеоплеер.
   - Фильтрация по проектам.

5. **Центр поддержки & Тикеты от клиентов**:
   - Прием обращений клиентов с сайтов, ботов и форм.
   - Мгновенный богатый пуш в Telegram с кнопками прямо в чате: `[⚡ В работу]`, `[✅ Решено]`, `[📱 Открыть в Mini App]`.

6. **Кастомизация фона (Живые видео-обои & Галерея)**:
   - Поддержка живых видео-обоев (зацикленные MP4/WEBM видео-фоны).
   - Загрузка любого фото из галереи или выбор кибер-градиентов.
   - Регулировка размытия фона (Backdrop Blur) и прозрачности карточек (Glassmorphism).

7. **Интеграция с другими вашими проектами (Project API)**:
   - Каждый проект имеет собственный `Project API Key`.
   - Готовые сниппеты для cURL, Python, Node.js, PHP.
   - Готовый HTML/JS виджет кнопки «💬 Поддержка» для вставки на сайты клиентов.

## 🚀 Быстрый запуск локально

### 1. Установка зависимостей:
```bash
# В корне проекта:
npm run render-build
```

### 2. Настройка переменных окружения:
Откройте файл `backend/.env` и заполните:
```env
BOT_TOKEN=ваш_токен_от_BotFather
ADMIN_CHAT_ID=ваш_chat_id_в_телеграм
PORT=5000
APP_URL=https://ваш-домен-или-ngrok.com
```

> [!TIP]
> Приложение можно запустить и **без токена бота** — система автоматически включит режим эмуляции (демо-режим), и все уведомления будут сохраняться в локальную базу данных и логи.

### 3. Запуск сервера:
```bash
npm start
```
Приложение откроется на `http://localhost:5000` (или в Telegram Mini App).

## 🤖 Как подключить бота и Mini App в Telegram

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram.
2. Создайте бота командой `/newbot`, скопируйте полученный токен в `backend/.env` (`BOT_TOKEN`).
3. Чтобы сделать Mini App кнопкой в меню бота:
   - Отправьте `/newapp` в `@BotFather`.
   - Выберите вашего бота.
   - Укажите название: `Lerman Mini App`.
   - Введите описание и загрузите аватарку.
   - Укажите URL вашего приложения (например адрес на Render: `https://lerman-app.onrender.com`).
   - Укажите короткое имя приложения (например `app`).
4. Готово! Теперь вы и ваши клиенты можете открывать приложение по кнопке внутри бота!

## ☁️ Деплой на Render.com (Бесплатно)

Проект изначально спроектирован для запуска на **Render.com** в виде одного Web Service:

1. Загрузите код в ваш **GitHub / GitLab** репозиторий.
2. Зайдите на [render.com](https://render.com) и нажмите **New + -> Web Service**.
3. Подключите репозиторий с проектом.
4. Настройте параметры:
   - **Name**: `lerman-mini-app`
   - **Environment**: `Node`
   - **Plan**: `Free`
   - **Build Command**: `npm run render-build`
   - **Start Command**: `npm start`
5. В разделе **Environment Variables** добавьте:
   - `BOT_TOKEN` = Ваш токен Telegram бота
   - `ADMIN_CHAT_ID` = Ваш Chat ID в Telegram
   - `APP_URL` = URL сервиса Render (например `https://lerman-mini-app.onrender.com`)
6. Нажмите **Deploy Web Service** — через 2-3 минуты приложение будет развернуто в интернете с бесплатным SSL-сертификатом (HTTPS), что идеально подходит для Telegram Mini App!

## 🔌 Как связать Lerman Mini App с другими проектами

В самом приложении во вкладке **«Интеграция»** доступны готовые сниппеты с подставленным API-ключом выбранного проекта.

### 1. Отправка тикета поддержки от клиента (JavaScript):
```javascript
fetch('https://ваш-сервер.onrender.com/api/v1/projects/event', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'x-api-key': 'ВАШ_PROJECT_API_KEY'
  },
  body: JSON.stringify({
    type: 'ticket',
    clientName: 'Александр',
    clientContact: '@alex_dev',
    message: 'Пофиксите ошибку 500 на оформлении заказа',
    level: 'danger'
  })
});
```
*В ту же секунду вам в Telegram придет push с кнопками «В работу» и «Решено»!*

### 2. Оповещение об обновлении приложения / сайта:
```bash
curl -X POST "https://ваш-сервер.onrender.com/api/v1/projects/event" \
  -H "Content-Type: application/json" \
  -H "x-api-key: ВАШ_PROJECT_API_KEY" \
  -d '{
    "type": "update",
    "version": "v2.1.0",
    "releaseNotes": "1. Новый модуль киберзащиты\n2. Исправлены зависания"
  }'
```

### 3. Готовый виджет для клиентских сайтов:
Просто скопируйте готовый сниппет из вкладки **«Интеграция»** и вставьте перед `</body>` любого клиентского сайта.
